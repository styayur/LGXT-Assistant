# Optional offline equation previews

The question-document export panel has an opt-in bitmap preview for the separately retained recognized LaTeX field. Install `requirements-equations.txt` when running the desktop/browser channel from Python source. Existing Markdown, text, tables, code, images and the complete LaTeX/Markdown sidecar are retained. Preview images are not editable Word OMML equations, and they do not establish OCR accuracy.

The pinned renderer is **Matplotlib 3.11.2 Mathtext**, using its bundled DejaVu Sans math fonts. Mathtext is a limited TeX-like parser and needs no TeX installation. `text.usetex` is explicitly false. Matplotlib uses a PSF-based, BSD-compatible license; bundled fonts retain their own notices in the upstream distribution. No renderer/font files are copied into the application or an Android package by this change. Repackaging the optional dependency requires retaining Matplotlib's and its fonts' original license/copyright files. Sources: [Mathtext](https://matplotlib.org/stable/users/explain/text/mathtext.html), [licenses](https://matplotlib.org/stable/project/license.html).

The source limit is 1,024 characters and 16 brace levels. File/network/macro commands and environments are rejected before parsing. A trusted Python child process runs with an isolated temporary working/font-cache directory and a ten-second deadline; it never executes a shell or a TeX engine. The child sets the documented [`MPL_IGNORE_SYSTEM_FONTS`](https://matplotlib.org/stable/install/environment_variables_faq.html#mpl-ignore-system-fonts) option: only the renderer's bundled fonts are scanned, avoiding Windows system-font enumeration on each cold start. Output is limited to a verified PNG of at most 1,000 × 500 pixels and 2 MiB. The child is joined/terminated before its temporary directory is removed.

Fractions and radicals are supported examples. Matrices, aligned environments, overly long or malformed expressions, a missing/wrong renderer version, timeouts and frozen application builds fall back to the retained source. They are not silently described as successfully typeset. Frozen installers and Android continue using source-only exports; enabling a renderer in such a distribution requires its own dependency, font, process-launch and package acceptance work.

`scripts/check_equation_exports.py` generates self-authored fraction, radical, matrix, aligned and long-expression fixtures in both formats. The compatibility job reopens Word files through LibreOffice, verifies source/picture/table preservation after round-trip, and renders both PDF outputs for visual review. These artifacts are QA evidence, not released product assets.
