01 · GET STARTED下载与校验

所有文件均在 GitHub Releases 发布； 下载后建议用 SHA256SUMS.txt 校验完整性。

# Windows PowerShell
Get-FileHash .\LGXT-Assistant-3.2.1-android.apk -Algorithm SHA256
certutil -hashfile LGXT-Assistant-3.2.1-setup.msi SHA256

# 查看签名（当前为自签名证书，UnknownError 属预期）
Get-AuthenticodeSignature .\LGXT-Assistant.exe | Format-List Status,SignerCertificate

02 · ANDROID（主推）手机版安装与使用

安装

  1. 手机浏览器打开 Releases，下载 LGXT-Assistant-3.2.1-android.apk；
  2. 进入「设置 → 应用 → 特殊应用权限 → 安装未知应用」，允许浏览器或文件管理器安装；
  3. 点击 APK 安装；若提示「应用未安装」：先卸载旧版本、确认剩余空间 ≥ 200MB、关闭安全中心拦截后重试。

使用步骤

  1. 登录：输入理工学堂账号与密码；可勾选「记住账号密码」（保存在 App 本地存储）。 若长时间停在 CONNECTING，v3.2.1 会在 20 秒后提示超时，可点「取消 / 重试」。
  2. 仪表盘：查看待激活、已完成作业数量与平均分，点 REFRESH 重新统计。
  3. 课程：底部导航「课程」→ 选择科目。
  4. 作业：查看状态（剩余次数 / 已完成 / 已用完）与截止时间 → 点「查看题目」。
  5. 题目：查看题面与图片 → 右下输入 0–100 → 点 SUBMIT 提交成绩。
  6. 返回：页面返回箭头或手机返回键逐级返回上一级菜单；根菜单（仪表盘/课程/设置）连按两次返回才退出。

说明：移动端不含 Word / PDF 导出，请在 Windows 版使用导出功能。

03 · WINDOWS桌面版安装与使用

安装

  • MSI（推荐）：双击安装（用户级、无需管理员），从开始菜单启动； 卸载：设置 → 应用，或 msiexec /x LGXT-Assistant-3.2.1-setup.msi /qn。
  • 单文件 EXE：双击运行；SmartScreen 提示时选「更多信息 → 仍要运行」。
  • 便携版 ZIP：解压到普通目录后运行 LGXT-Assistant-portable.exe。

使用步骤

  1. 登录：AUTH 面板输入账号密码，可勾选「记住密码」（写入 Windows 凭据管理器）。
  2. 仪表盘：侧栏「仪表盘」→ 待激活 / 已完成 / 平均分。
  3. 课程星图：侧栏「课程星图」→ 单击恒星展开科目的作业行星（按需加载）→ 单击行星进入题目。 行星颜色：绿=可提交、橙=最后一次、红=已用完、蓝=已完成。
  4. 作业区：左列表支持搜索 / 筛选 / 排序；右侧 Inspector 显示章节、截止、成绩、尝试次数与状态。
  5. 题目区：三栏布局（题目列表 / 题面图片 / 答案与成绩提交）。
  6. 设置：导出格式与是否含答案、导出路径、界面音效；右侧 SYSTEM 显示 API、版本、许可与登录状态。

04 · EXPORT题目导出（Windows）

  1. 在设置页选择导出路径与格式（Word / PDF，是否含答案）；
  2. 单作业：作业 Inspector 内点 EXPORT 题目；
  3. 当前课程：作业页 EXPORT ALL；全部课程：星图页 EXPORT ALL；
  4. 产物目录：<导出路径>/作业/<课程>(ID_x)/<作业>(ID_y)/ 内含 题目图片/、.docx、.pdf；
  5. 重复导出时已存在的题目图片会跳过下载，节省时间与流量。

06 · FAQ常见问题

现象处理方式
手机禁止安装允许「安装未知应用」后重试
提示「应用未安装」卸载旧版本、清理空间、关闭安全中心拦截
登录停在 CONNECTINGv3.2.1 已修复：20 秒超时提示，可取消/重试；仍失败请检查网络
Windows 未知发布者自签名证书所致，选择「仍要运行」，或使用自有 CA 证书签名
星图展开失败确认网络后再次单击该恒星重试
导出失败检查导出目录是否可写；结果弹窗会显示原因

07 · DEVELOP开发与构建

# Windows 桌面版
pip install -r requirements.txt
python default.pyw

# 测试（CI 也运行）
pip install -r requirements-dev.txt
python -m pytest

# Android APK（云端）
gh workflow run android-apk.yml
gh run download -n lgxt-android-apk

# Android APK（本地，需 Flutter 3.24.x + Android SDK + JDK 17）
pip install flet==0.25.2
cd mobile && flet build apk

# Windows 打包 / MSI
powershell -ExecutionPolicy Bypass -File packaging\build_exe.ps1
powershell -ExecutionPolicy Bypass -File packaging\build_msi.ps1 -WixBin <wix3>
