# Assignment workspace guide / 作业工作区使用说明

This guide describes the assignment upgrade candidates, not historical 4.0.1 binaries. See the release page for actual availability. / 本说明对应作业升级候选版本，历史 4.0.1 不包含这些新增功能。

1. Open **我的课程**, log in and choose a course, assignment and question. The official endpoint is HTTP and HTTPS is unverified. Plaintext access is blocked unless you explicitly accept its risk for this login. Keep the persistent warning in mind; credentials are not saved in compatibility mode.
2. The original image is the source. Click it to open at full size. **图片转 LaTeX** sends it to your configured vision service; crop controls specify left/top/width/height percentages of the original image. The full source stays intact.
3. In **检查识别结果**, correct text and LaTeX, inspect the rendered preview and select **应用校正结果**. Recognition is machine-generated and can be wrong. Editing is local until you initiate another AI operation.
4. Edit the question source and rich-text solution. Click a formula to change its LaTeX. Use **Markdown 源码 → 转换并应用** for explicit import; preserve the original if a dialect is unsupported. The local image picker supports PNG/JPEG/WebP up to 2 MB. Do not paste secrets into documents.
5. In the question's AI panel, select text sources from the existing workspace, decide whether to include the image, and click **使用 AI 分析此题**. This sends the displayed context to your configured service. First verify vision capability in **设置 → AI 模型**; remove images for text-only models. Add a reviewed reply to the solution before asking for its revision. AI is fallible; source labels are context provenance, not fabricated citations.
6. Select **保存题目文档**. Unsaved changes are indicated; save before navigating. Previous versions remain in `.previous.json` next to hashed question files under `%APPDATA%\LGXT-Assistant\desktop`. Exports are written to the configured export directory under `question-documents`. Markdown keeps full source. Word/PDF preserve basic blocks and original image; formulas are LaTeX source. Validated embedded editor raster images are included. Remote images are not downloaded.
7. **一键满分** is available at course, assignment and all-course levels. Check scope, count, target 100, known attempts and incomplete retrieval. Confirm once to change server records. **停止后续请求** stops scheduling future writes; committed changes cannot be rolled back. `succeeded` means the platform acknowledged the request; `verification_required` means check the platform before attempting again. No reliable independent final-grade/attempt verification API is known.
8. Android has a separate Flet interface: original image zoom, Markdown/LaTeX correction, local saved question notes, recognition and contextual analysis. Enter an OpenAI-compatible HTTPS vision endpoint, model ID and key for this session. It does not provide the desktop rich editor, crop or Word/PDF export. Source controls are checked at 390×844 and reduced keyboard height; these are not signed APK or physical-device tests.

中文要点：原图为准；识别后先校正；AI 发送由用户明确发起；勾选资料才引用；切换页面前保存；Word/PDF 公式目前保留源码；一键满分先核对范围与数量，超时先到平台核实，取消不能撤回已提交更改。

Back up local data while the app is closed. Keep original images and Markdown sidecars with exported documents. The old 4.0.1 PDF guide remains historical and is not included as the new release guide.
