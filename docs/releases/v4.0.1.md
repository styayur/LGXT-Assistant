# LGXT Assistant 4.0.1

这次 Windows 更新带来全新的三栏桌面界面，并修复多种导致用户无法进入或一直等待的情况。

## 下载后使用

- **LGXT-Assistant.exe**：单文件版本，下载后双击运行。首次启动需要准备文件，请稍等。
- **LGXT-Assistant-portable.zip**：完整解压后运行其中的 `LGXT-Assistant-portable.exe`，保留 `_internal` 文件夹。压缩包内附使用说明。
- **LGXT-Assistant-4.0.1-User-Guide.pdf**：13 页中文说明，面向使用者，包含安装、登录、课程、AI 对话、导出、备份和故障排查。
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验值。

适用于 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。普通使用者无需安装 Python 或 Node.js，请勿将 GitHub 自动提供的 Source code 当作安装包。本次不提供 MSI 或新的 Android APK；Android 用户继续使用历史 v3.2.1 版本。

## 修复无法进入

- 等待桌面连接就绪后再加载资料；连接失败时显示重试提示，避免静默进入浏览器预览模式。
- 系统凭据库响应缓慢不再阻塞主界面；单条历史会话读取失败不影响进入。
- 损坏的偏好、会话索引等本地资料先备份，再使用可用内容；旧配置中的非法开关值和含 `%` 的路径不再导致启动异常。
- 课程登录等待超过 20 秒会恢复操作并显示错误，可取消或重试；已取消的请求不会随后自动登录。
- 缺失界面资源、依赖或 WebView2 时显示启动帮助，提供兼容界面、运行时下载和完整安装包入口。

## 新版桌面

深色、浅色与跟随系统主题；可折叠导航与上下文面板；AI 流式对话、停止、编辑、重新生成、复制和导出；Markdown、代码高亮、公式与表格；会话历史、文件引用、工作区任务与提示词库；模型服务配置、连接测试和命令面板。

课程、作业、参考答案、题目图片、Word / PDF 导出及需确认的成绩提交继续保留。课程账号和 AI 模型分别连接，未配置 AI 不影响课程功能。旧 Tk 界面可通过启动帮助或 `--legacy` 打开。

## 更新与验证

关闭旧版后，将新版解压到新文件夹。资料保存在 `%APPDATA%\LGXT-Assistant`，更新前可复制该文件夹备份；系统凭据库中的密码和密钥需要单独管理。

发布流程先执行 Python 测试、前端构建、浏览器交互测试，再验证单文件 EXE 和从 ZIP 解压的便携版确实能加载本地界面并完成 Python 桥接，全部通过后才发布附件。示例截图使用测试数据；未使用真实账号执行成绩提交或付费模型请求。
