Android 3.3.0 Beta — reinstall required

**Existing Android 3.2.1 installations cannot update in place.** This Beta uses the new durable signing identity explicitly approved by the maintainer. Before uninstalling, export and independently verify any local question-document backups and keep them outside app-private storage. Uninstall deletes private data/preferences. Install this signed Beta, import the saved documents, compare their contents, and retain the external backup until recovery is confirmed. The original 3.2.1 predates question-document export; modified builds without an export facility must preserve valuable data through their existing backup/export mechanism or manual copies before uninstalling.

**旧版须先备份并核对资料，再卸载重装。卸载会删除应用私有数据与设置。** 题目文档备份不包含账号密码、API Key 或全部应用状态；原版 3.2.1 没有题目文档导出按钮，请先确认实际安装版本的资料已妥善保存。
