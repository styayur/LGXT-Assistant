# Android 3.3.1 Beta

Android is the active product. Existing Windows releases/history remain available;
this release adds no Windows Desktop or Windows Web features.

- Keep the requests session that logged in, including its response cookies.
  Preserve the historical form endpoint/field/header contract and readable errors.
- Explicit, remembered HTTP compatibility choice with a persistent plaintext
  warning. No TLS bypass, URL rewrite or global Android cleartext permission.
- Optional Android Keystore-backed token/cookie restoration, limited to the same
  API origin and seven days locally, with a fresh server check. No password saved.
  Logout clears the device session; offline notes remain usable on network failure.
- Material 3 semantic light/dark themes, pending assignments ordered by deadline,
  progress based on loaded server data, partial-load errors, direct task entry,
  readable metadata and accessible native controls. Existing question images,
  editable LaTeX source, notes, AI actions and offline materials remain in Flet.
- Version code 5, unchanged package, durable signing certificate and schema-1 notes.
  Upgrade directly over 3.3.0 Beta. Historical 3.2.1 still requires backup/reinstall.

Only signed release assets that pass native acceptance qualify for publication.
Real platform login and physical ARM64 compatibility require an available lawful
account/device; synthetic tests do not establish those results. OCR accuracy and
paid-provider quality remain unverified.
